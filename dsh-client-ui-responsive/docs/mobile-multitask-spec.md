# 移动端双工作区规格与验收

基线：UI main e435af531ec0fbf864db960f6ef6fdaa0eda78f2；APK main a10d2306ea3ab770c1beadaa67f4bfbd59b478c5。原工作树不参与修改。UI 主仓先同步 APK 已交付的 0.2.1-rc.2 依赖、旧 invariant/模型能力退役与弹层避让修复，再实现本轮行为；不把旧依赖重新镜像回 APK。未发版。

## 已确认的交互

- 侧边栏覆盖主对话，不占主对话布局；两个工作区均在覆盖层内部。竖屏上下、横屏左右，初始50:50。
- 点击普通药丸退出分屏并全屏显示该标签。第二工作区的选择开始页在该工作区打开所选标签。
- 长按400ms激活排序，标签堆外24 CSS px安全区、越界稳定150ms后出现分屏预览，释放才提交。回到安全区/取消不改变原顺序。
- 分栏创建标签选择页；两个工作区只接纳独立分屏能力允许的不同标签。未知类型默认拒绝。虚拟屏保留专用生命周期。
- 顶部握柄拖到另一工作区交换位置。标题、内容、焦点以paneId/tabId绑定。独立分隔条实时调整、双击归中；按可用尺寸夹紧。
- 分栏右侧小窗按钮将当前标签浮窗化，停靠区显示最近访问的可用标签。拖出不再触发浮窗。无其他标签时显示选择页。
- 竖屏隐藏用途重复的上游全屏模式按钮。返回和关闭继续由现有生命周期管理。

## 架构与限制

复用上游DockLayout稳定TabHost和原生store actions，不挪动正文DOM、不创建第二份Agent。移动端适配单独封装到mobile-workspaces：一个版本约束适配面读已adopt的Session store，所有写入调用原生actions。原生row双窗格状态保持不变，竖屏仅转换网格显示方向；比例沿用原生持久化。交换按稳定paneId映射物理位置。会话资源增加keepMounted。

能力以显式kind表声明：conversation、subagentchat、terminal、browser/android-browser；原生浏览器同时最多一个呈现，两个browser不能组合；android-vdisplay不走通用分屏。未知类型拒绝并显示原因。适配面失配必须禁用并说明，不猜测私有字段。

## 视觉与边界修订

- 分栏和小窗使用专属属性选择器，横向等宽排列，实体背景、999px 圆角、无阴影；小窗位于分栏右侧。主题色提升到右侧面板共同祖先，标签、入口与工作区握柄共用同一组 Token。
- 拖出后的非拖拽标签由46px收缩至24px，保留7px间距和选中背景；恢复动画160ms。不使用按索引平移，避免大量标签互相重叠。24px安全区与150ms稳定等待保持不变。
- 两个工作区各自保留44px透明控制带，标题不接收触摸；原生标签头在分屏下隐藏但保留DOM作为稳定身份和状态来源。
- 独立分隔控制条采用20px透明命中轨道、2px视觉线。网格、CSS变量和拖动/键盘比例计算共用DIVIDER_HIT_SIZE，保证整条可操作和极限比例一致。
- 选择页签名包含稳定ID、标题、类型、内容身份及能力。无候选时显示状态文字，有不兼容标签时显示可见原因。仅删除本次操作新建的占位标签，已有真实标签不得作为可删除占位。
