# 拖动对话到右侧栏

左侧会话行或子代理列表项长按约 400ms 后，屏幕右缘显示蓝色接收区。拖入并松手即可侧开对话，右栏自动展开，主对话保持原位。普通点击、滚动与原有会话排序继续使用原路径。

空间较窄时侧开会自动收起左侧导航，给主对话与右栏留出位置。等待布局及原生宽度测量更新后再打开资源；期间切换主对话或卸载插件会取消待处理操作。右侧覆盖层内最多两个工作区。竖屏上下、横屏左右，两个正文均可交互。点击标签药丸退出分屏并全屏显示该标签；分栏按钮创建标签选择页；小窗按钮将当前标签浮窗化并回退最近标签。分隔条调整比例，双击均分，顶部握柄交换位置。主对话布局不被覆盖层挤占。完整规则与能力限制见 [移动端多任务规格](mobile-multitask-spec.md)。

普通对话通过 conversation 资源持有独立 SessionReference。关闭标签或卸载资源时释放引用，不调用主区域的会话导航。子代理以运行时目录的完整行序、层级与标签核对弹窗条目，保留直接父会话地址及模式，复用同一资源入口。目录不一致时不猜测身份。两类入口分别保留。按真实子会话 ID 跨 conversation 与 subagentchat 地址查找已有标签，重复拖入只定位已有视图；不以标题或标签数组下标充当身份。会话、子代理和终端视图在隐藏与迁移期间保留挂载。

拖入前先把排序拖动结算为源行无操作，再调用侧开入口。取消、多指、移出接收区或组件卸载均清理拖动状态与蓝区。接收区贯穿屏幕高度，没有描边和上下边界。淡蓝雾光从右向左渐隐，轻度毛玻璃随渐隐遮罩融入界面；白色文案随手指位置切换：拖动已开始、尚未进入接收区时为「拖到此处以在侧边栏打开」，进入接收区后才变为「松开于侧边栏打开」，移出即退回前者。拖入时增强反馈，退出时淡出。右侧面板只在边缘增加低强度光晕和窄幅毛玻璃，正文与输入框保持清晰。动效尊重系统减少动态效果设置。

开发验证记录见 PR；热推验证仅覆盖设备运行树，不代表最终 APK 验收。发版前需重新构建并验收实际 APK。
