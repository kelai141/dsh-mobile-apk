# WebUI 导航与返回

审查基线为 APK 仓 `4050ea675bf6e9ac4bda4a827c60aef93d0cde48`。协调仓根级响应式客户端是同源映射。检查入口包括响应式客户端的插槽注册、固定版本的引擎 overlay、vendored 市场与订阅插件、Android 的 WebView 建立点和下载站。设置和面板的实际注册项取决于启用的插件与账号状态。

## 页面树与直接返回目标

| 父级 | 子页或临时层 | 返回入口及目标 |
|---|---|---|
| Android 任务 | 主 Activity 的启动视频 | Android 返回关闭视频，露出其后的页面 |
| Android 任务 | 引导根页 → 管理中心 → 管理子面板 | 按键和已提交手势经 `GuideManagementController.back` 退直接父级。取消手势恢复动画 |
| 管理中心 / 开发者选项 | 独立终端控制台 `ConsoleActivity` / `console.html` | 控制台退出按钮结束 Activity。系统先关 IME，再按 Activity 任务栈返回启动者 |
| 手机控制 Root 权限 | 免责声明 WebView | Android AlertDialog 独占窗口。关闭按钮与系统返回销毁文档 WebView，回到 Root 权限 |
| 主 WebView | 会话根页（欢迎页、选中会话、空工作区） | Android 先尝试 WebView 历史，随后调用 Activity 默认返回。选中会话和工作区由上游服务管理 |
| 会话 / 当前主面板 | 手机左侧抽屉 | 菜单及对话框优先。抽屉返回切换布局的折叠状态。桌面停靠栏属于布局 |
| 左抽屉 / 会话页头 | 账号、工作区、会话菜单、视图选项、后台任务、子代理目录 | 模态菜单、上下文菜单或已标记的页头浮层先退。下层抽屉或页头折叠状态随后处理 |
| 会话页头 | 展开选项、分享或导出结果 | 对话框先退。页头展开状态经原披露控件收起 |
| 会话输入区 | 附件面板、指令菜单、文件引用菜单 → 目录面包屑、模型菜单 → 模型分组 | 附件面板走自己的关闭事件。文件引用回上一级面包屑，再退出菜单。模型菜单走组件的分组返回 |
| 会话消息 | 图片灯箱、轨迹事件详情、其他模态确认 | 灯箱与确认框走各自关闭控件或遮罩。轨迹详情关闭后回当前会话 |
| 会话 | 右侧页面（文档、文件、虚拟屏、终端、会话/子代理、浏览器） | 手机全屏右栏回会话，宽屏全屏切回原面板模式。折叠保留标签和当前资源 |
| 右侧浏览器 | 当前浏览器标签的文档历史 | 有上一级时复用该标签的工具栏返回操作。历史见底后 Android 才处理全屏右栏。前进按钮继续由浏览器标签的历史管理 |
| 会话 / 当前面板 | 插件管理根页 → 包 → 条目 → 配置行 | 明确的详情 DOM 与原面包屑负责各级返回。列表根结束使用布局服务 |
| 插件管理 | 实验性插件「更多」 | 复用页头原有返回键，回插件列表 |
| 插件管理 / 添加插件 | 内置市场、扩展市场全页 | 上游模态与第三方全页市场分别走自己的关闭控件。关闭后回原插件面板 |
| 左抽屉 | 任务管理及其他 `main` 扩展入口 | 面板根由上游 `panelInfo` 识别，回会话。插件新增专属子页时须提供稳定的锚点和退出动作 |
| 左抽屉 | Linux 环境 → 工具链 / 终端 | 唯一页头返回键与 Android 走同一分发。先回 Linux 概览，再回会话 |
| 账号菜单 | 设置首页 → 注册分区 | 手机端一层一退。宽屏保留上下游同屏分区布局，设置根关闭回打开前页面 |
| 设置分区 | 通用、模型、账号与余额、会话日志、插件设置/清单、代理循环与子代理、Shell、网页搜索、快照等上游分区 | 沿用 `settings.section` 注册项。设置页头负责手机分区回首页 |
| 设置分区 | 应用更新、通知、开发者选项、手机控制、Linux 环境、关于及条件注册的分区 | 沿用注册分区和设置返回条。上游激活状态继续由设置服务持有 |
| 通用 / 账号分区 | 关于 / 订阅 | 分区内跳转保留来源分区，按栈回退并恢复来源分区选择。订阅的可见入口依账号状态决定 |
| 手机控制 | 无障碍通道、Shizuku 授权、虚拟屏设置、高级设置与诊断、Root 权限 | 同一子层合约先回手机控制概览。Android 设置、安装器、授权窗口优先使用系统返回 |
| 设置 / Linux 环境 | 工具链 / 终端 | 设置页头或系统返回先回 Linux 设置分区，之后回设置首页。宽屏子页保留一个自己的返回按钮 |
| 下载站 | 首页锚点、架构、镜像源与校验说明 | 普通浏览器链接和页面内 disclosure。移动壳层协议不参与公网下载站 |

这里的「模态」覆盖基线中带 `role=dialog/aria-modal` 的 UI。新的第三方页面可能仅存在于可选插件的编译产物中。只有它声明了原有模态语义或有稳定的适配锚点，统一控制器才能分发其返回动作。单个可选插件的私有子页仍需用实际插件配置复查。

## 调用顺序

1. Android 窗口分发先由系统处理 IME、AlertDialog 与其他持焦窗口。主 Activity 的 `OnBackPressedDispatcher` 接收返回键和提交的预测手势。引导页动画只在引导页前台时接收进度。
2. 视频或引导层消费后即结束。主 WebView 显示受信引擎页时，壳针对当前文档发起一次 JS 请求。相邻输入在同一个在途请求期间合并。文档切换、渲染进程销毁和超时使旧请求失效。
3. `BackStackSignal.requestBack` 在处理时重新读取布局和可交互层。主面板、抽屉和全屏右栏构成基础层，浏览器文档历史和临时交互层在其上。模态用节点身份维持打开顺序，嵌套元素按父子顺序。组件自身的回调、独立子层事件和上游原有控件执行具体动作。
4. `handled` 表示分发到一个层，`blocked` 表示有层但未能执行，两者都消费本次返回。确认到根级后 WebView 才检查可回退历史，随后交给 Activity 默认分发。旧客户端的 `__dshBack` 与 `dshBackBridge` 用于快照升级兼容。
5. 浏览器 `popstate` 在历史遍历完成之后到达。控制器重读已恢复页面，路由、WebView 历史及前进由原浏览器管理。层级切换不写入 `pushState`、`replaceState` 等伪历史。

打开设置、进入分区和折叠右栏沿用原布局动作。设置首页隐藏分区内容列，因此保留仍挂载的输入和滚动。跨分区选择仍遵从上游分区挂载生命周期。Linux 终端离开视图时释放 xterm 和轮询，保留引擎会话，重进走现有 open 连接。刷新或进程重启使用上游已经持久化的会话和配置，临时模态从新文档实际状态重建。

## 同族问题与修复位置

| 发现 | 原因 | 修改 |
|---|---|---|
| 开着模态时系统返回能直接跳文档 | 壳先读历史，且渲染刚提交时缓存可滞后 | 当前文档应答先于根级历史 |
| 手机左抽屉返回一直被消费 | 上游抽屉同时带 ARIA dialog 语义，曾被当作抽屉和普通模态各入一层 | 通过 data-shortcut-modal 识别抽屉身份，只进入一次 |
| 多层模态在删除下层或 React 重挂时错序 | 索引被当作节点身份 | 改用节点身份并校正父子顺序 |
| Linux 工具链、终端从独立主面板直接退回会话 | 原子层注册只由设置外壳读取 | 两个入口复用同一子层退出动作 |
| Linux 设置出现额外回会话入口 | 分区自己渲染了根级返回 | 回退交给所属容器的唯一页头 |
| 手机控制子页可能把退出处理挂到另一个分区 | 绑定使用全局第一个子层节点 | 本页引用在布局提交时绑定 |
| 附件卡片与通用模态重复入栈 | 卡片同时拥有 aria-modal 和专属 backdrop | 卡片进入一次，统一分发时定向关闭。借用菜单和退场节点不入栈 |
| 实验性插件更多页退到会话 | 泛主面板只识别包、条目、行 | 给上游更多页的原返回键补父级适配 |
| 右栏浏览器在可回退时先折叠或走外层历史 | 内层工具栏历史没有参与 Android 分发 | 仅当前呈现且可用的浏览器返回控件入栈 |
| 设置内多次跨分区跳转只能记住一跳 | 单个 previousLabel | 用分区返回历史逐级恢复 |

## 验证

前端单测覆盖当前 DOM、模态顺序、返回失败消费、Linux 主面板子层与独立浏览器历史优先级。Kotlin 单测覆盖页面回执、历史回退和兼容信号。

运行 `node scripts/verify-webui-navigation.mjs --serial <serial> --json <file>`。套件以 CDP 获取实际控件和页面状态，经可信输入执行打开操作，用 `KEYCODE_BACK` 与页内返回触发对比，记录层级、History 和 Android 窗口焦点。用户本轮指定的取证只使用结构化结果，不使用截图。

## 轮询与更新审查

| 位置 | 原行为 | 本轮处理与证据 |
|---|---|---|
| 返回层观察器 | 会话流式文本更新可触发整页层级扫描 | 变更先按层锚点过滤，保留真实层插入和可见性更新。测试对 20 个无层级变化的批次计数，全文档查询目标为 0 |
| Linux 概览 | 空闲和安装中同样每 2 秒请求状态，恢复可见与周期任务可能重叠 | 安装期间 2 秒，空闲 12 秒。隐藏停读，恢复立刻读，状态请求单飞。自动查上游更新每次挂载最多一次 |
| Linux 终端 | 无输出时仍按 120 毫秒轮询 | 有输出后回到 120 毫秒，空闲退避到 800 毫秒。隐藏暂停读取，输入完成或回到前台立即调度。引擎终端不随视图暂停 |
| 应用更新 | 活动状态轮询可随 WebView 进入后台 | 后台跳过桥读取，回前台用既有可见性监听同步 |
| 外部附件草稿队列 | 每 4 秒定时读队列，后台仍运行 | 周期读取限于页面可见时，原生通知事件仍即时触发 |
| 浏览器舞台与虚拟屏 | 可见舞台需续租，避免原生 Surface 在遮挡或卸载后残留 | 保留现有活动性门控、租约和合帧。不能以页面读数间隔替换渲染舞台续租 |
| 订阅插件 | 支付中的轮询和用量刷新；模型/速度控件各有 3 秒周期 | 已审查 vendored 产物。模型/速度轮询仍可能重复，需要在订阅插件源头合并状态订阅与发布产物，当前未改 |
| Shell 状态及其他观察器 | 可见性/焦点桥读，部分观察器根据各自 DOM 锚点合帧 | 保留回系统设置后的即时同步。缺少实测热点证据的观察器保持当前触发条件 |


## 手机附件面板的底部锚点

竖屏 Sheet 的固定遮罩覆盖整个布局视口，面板相对遮罩底边绝对定位。输入法打开时先保留遮罩，等待键盘关闭后启动入场动画。视觉视口的滚动和宿主的键盘避让量不调整 Sheet 的底边和展开上限。关闭过程结束前，浏览器与虚拟屏原生舞台继续让位。宽屏卡片沿用居中形态。

设备套件检查底边间距、顶层命中和静态锚点，并注入一次模拟 IME 通知核对底边及高度上限。实际键盘收起时序与原生舞台组合另有不同于此模拟事件的验收条件。
