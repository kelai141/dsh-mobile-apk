## 当前交互不变量与回归映射

| 需求 | 当前不可降级判据 | 必须覆盖的反证/边界 |
|---|---|---|
| 入口：自由球与边缘strip | 默认球可自由拖动。显式球/条选择只在应用设置，不在顶部输出放形态按钮。球先拖到左/右边贴边，再继续朝该边缘侧滑才转strip；strip向屏内拉出恢复自由球，可跨屏拖到另一侧再侧滑收条，左右对称 | 单纯到边不误变形；向外/向内方向区分；左→右、右→左均可；与系统边缘手势不串 |
| 原有入口原语 | 点击展开/切换顶部、双击进本体、长按顶部+独立输入等既有原语保持；本体前台入口隐藏/禁用规则保持 | 边滑拖动不能补发点击/双击/长按；设置与手势不产生两份入口 |
| 顶部输出 | 运行与空闲都可读当前会话真实user/assistant历史。助手正文按Markdown呈现，工具调用按类似DSH的可辨识结构展示；多行可滚，角色/工具/思考不互相冒充 | 已有会话重开、idle、流式更新、切sid不串；稳定row更新保用户滚动，不强拉到底 |
| 顶部内容空间 | **右上X、形态、隐藏按钮全部移除**，不以图标/占位行继续占内容；显式球/条设置仅应用设置 | 无上述按钮与不可见热区；不能以旧按钮承担当前手势需求 |
| card→长胶囊 | 白条拖动上推时跟手、以非线性形变**直接收成长条胶囊**，不是松手后短状态pill突然替换。既有长按识别原语保留，但不要求高速；下拉到40%上限路径保留 | 慢拖/停顿可完成；不足平滑回弹；曲线连续、不每帧重测历史或WM高度；当前距离/时长数值可配置待实测 |
| 长胶囊内容 | 保留一行**最新真实Agent可见输出**，不是仅“运行中/空闲”等状态。状态可作辅助，但不能代替输出；无真实输出须如实表达，不编造 | 新输出持续更新、完成/idle后仍是真内容；单行省略不能冒充整段历史 |
| 长条顶缘收起 | 拖到顶部限位区本身不隐藏；继续向上先经过宽容区，超出后按继续上推距离渐淡/收起，未到收起条件松手则回弹。**不要求高速，也不强制另一次新DOWN** | 顶部停住不隐藏、宽容区内不误收；距离/alpha连续，取消/不足恢复可见态；未确认数值不写死 |
| 长条联动收口 | 长条明确收起时，同时收当前底部输入、IME及选择sheet，保原草稿/历史、Agent继续 | 不能只收长条留下透明触区/键盘/sheet；不停止服务、取消任务或清草稿 |
| 中间空白/F17 | 点击顶部与底部之间空白或输入外部，只收底部输入/sheet与键盘，顶部输出保持。顶部改变由入口原语或白条/长条手势控制，不再有顶部X/形态/隐藏按钮 | 顶部误关、IME未收、草稿丢失或下层tap被无形区域吞均为失败 |
| 浮动输入与chips | 工作区/会话chips各自浮动、无整行共用底板；输入四周完整圆角、与底边留隙，不是贴底大面板。真源/F19答题与message草稿隔离、附件/真实预览/删除保留，不做语音 | 真实IME/导航/配置变化适配；不能把共板只改透明色冒充独立布局 |
| 独立底部sheet | ＋打开独立底部sheet，覆盖其它app及input，**input原位置/尺寸不变**；不inline撑高、不改composer的x/y或resize作避让。动态命令与附件入口沿原真源 | 打开/关闭sheet前后input坐标尺寸一致；alpha/translation有限动画，不height动画/全屏透明拦截 |
| picker/camera原窗原草稿 | 发起系统取件/相机不得主动hide/remove浮窗、重建View或清草稿；保原session/text/selection。为不抢系统焦点触摸可临时NOT_FOCUSABLE/NOT_TOUCHABLE，结束恢复每窗原flags；取消原样、成功仅append附件到发起目标 | 同View/位置/会话/文字/选区/flags前后对照；不能以“隐藏后重建保文本”代替；不得隐式新建会话/覆盖原refs |

## 澄清时序：哪些仅属历史

1. 早期将F17解释为“点外部关顶部”、采用贴底共板input及inline height抽屉；后被用户纠正为空白只收底部、独立sheet/浮动chips。旧报告保时序，旧判据不再当前生效。
2. 此前白条仅支持快fling，后来补系统longpress后48dp慢推；**48dp/500dp/s、短pill44dp、顶缘16dp/500dp/s/8dp、必须新DOWN的二次消散均是旧施工参数/解释**，不能据旧单测绿色拒绝当前连续形变与距离宽容区收起。当前数值/曲线应可配置并待实测确认。
3. 曾以prepare时撤card/pill/composer、receipt后show重建解决Picker遮挡；用户明确否定。现在只允许同窗临时交互flags让行，成功/取消保原session/text/selection，不以取件为重建/隐藏理由。
4. 最新又明确card收为展示最新Agent输出的长胶囊、顶部Markdown/工具调用类DSH、长条到顶后的宽容区渐淡联动收底部，以及移除顶部所有X/形态/隐藏按钮、对称球↔strip边滑规则。本页和设计的当前条款已替换旧解释，不两套并行。
5. 各旧实现/测试结论只覆盖当时输入。**当前已继续实现；CURRENT VERIFICATION PENDING**，源码存在、局部测试或文档同步均不代表最新交互通过。实际结果仅由lead维护[测试报告](<test-report-phase2.md>)。

## 架构、视觉与兼容约束

- Kotlin原生负责窗口/绘制/手势/动效/生命周期；不全面Rust化、不做SwiftUI/高成本Liquid Glass。
- 复用Runtime、会话/工作区、公开历史/事件、消息/附件/动态命令真源，不维护另一份命令表/假历史，不做第三方插件专用适配。
- 使用既有启动页颜色/圆角/字体等资源；可低成本降级材质，但不能用“降级”改变交互目标。
- 稳定row与有界投影，动画以alpha/translation和受控非线性形变为主，不逐帧height/WM resize、无事件不常驻刷新；系统关动画/脱离窗口及时终态与撤订阅。
- 32%/40%顶部比例等尚未被改动的约束保持；形变曲线、长条尺寸、顶部限位/宽容区/收起距离、边滑距离等**未确认数值均可配置/待实测**，不自编产品阈值或性能通过值。

## 验收与完成标准

- 每个模块记录对应输入/环境/命令/结果；编译/局部单测不是验收，必须代码/CDP/ADB用户层与横竖屏真实交互证据。
- 按上表逐项覆盖成功、取消、不足/宽容区、慢拖、左右对称、历史/输出真实性、sheet覆盖不抬移、系统取件同View/草稿与flags保留；不得用负屏坐标、假正文或旧参数反证代替用户任务。
- 旧失败记录保留，未通过不豁免；CPU/PSS/帧时/延迟/长稳同设备同输入比较，未知保持待测，不编数据。
- 只有功能、跨层、体验、性能/兼容与最终产物证据齐全才完成。任何未测/旧输入失效边界必须明确，不能由本轮文档更新推出已实现或已验收。
