# Clipboard model configuration drafts

Issue #584: copying a structured configuration should populate the currently edited provider without storing credentials or changing settings until its existing Apply action is used.

The upstream provider-card extension slot exposes metadata but no draft setters. The UI adapter therefore observes actual provider editors in Settings or a visible modal onboarding dialog and writes their controlled inputs through the native value setter and normal React input events. It never invokes Apply or credentials/settings operations. JSON and key=value aliases support apiKey, baseURL and model; a plain single-line key is also accepted. The parser caps input at 16 KiB, rejects duplicate/escaped aliases, unsupported nested values and unknown fields, and refuses endpoint credentials/query fragments. Errors contain reason codes, never clipboard values.

The read action opens a foreground native confirmation before clipboard access. ClipboardReadController owns one bounded request and page identity. Cancellation, navigation, Activity pause/destruction, monotonic expiry and request epochs prevent late reads/publications. Only one plain-text item is read; URIs and intents are not coerced. The preview masks the API key. Model filling requires an explicit field choice when several rows exist. Hidden, disabled, edited, detached or ambiguous targets are rejected; closing the editor removes its listener and preview.
