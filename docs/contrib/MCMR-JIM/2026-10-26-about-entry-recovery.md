# About entry recovery

**A handled React node does not guarantee its injected sibling still exists (#563).** About navigation remembered successful installation and hid the fallback row, while mutation repair only re-hid the upstream version node. Removing the injected button therefore removed both reachable entrances. The same idempotent operation now restores the button and recovers its version marker after module reload; unrelated chat mutations do not rescan settings. Returning from a hidden active navigation row selects a visible enabled focus target without changing upstream selection. Validation: four added regressions fail against the original implementation; all 906 UI tests and the package build pass after the correction. A Chromium fixture exercises entry removal, recovery, navigation and visible focus in portrait, with a wide-layout check. Android 15 / WebView 124 acceptance passed in portrait and landscape: the removed entry recovered exactly once, navigation remained reachable, and return focus selected a visible enabled target. Both WebView verification runs passed all 39 checks.
