# Byte fidelity for registered build inputs

**Text checkout conversion changes hash-bound build inputs (#597).** The official streaming patch and captured fixture identities and distributed SDK licenses plus the verbatim browser stylesheet are registered by raw SHA-256, but autocrlf converted their LF bytes to CRLF. Engine assembly then rejected the unchanged official patch, and fixture gates reported identity drift. Git attributes now preserve hash-bound assets and the legacy recovery core exactly, while build scripts and profiles use LF for POSIX consumers and exact-context tests. Eight regressions compare actual bytes and forced-autocrlf checkout filtering against registered identities; restoring the original attributes makes four checkout-sensitive cases fail. Fixture and patch-regression gates pass with canonical source bytes.
