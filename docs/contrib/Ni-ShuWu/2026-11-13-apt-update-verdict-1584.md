# 换源校验必须同时确认进程与输出（#1584）

- 现象：apt 非零退出但没有旧清单中的失败文本，或管道读取失败导致空输出时，换源被误判成功，不执行回滚。
- 真因：`ProcResult` 没有退出码；`runAptUpdate` 只排除超时，再用少量输出标记判定成功，没有使用 `complete` 或截断状态。
- 修法：`ProcIo.readBoundedMillis` 返回自然退出码，超时或取不到状态时为 null；不改变既有 `complete` 的 I/O 语义。`SourceSettings.aptUpdateFailure` 仅接受完整、未截断、已知零退出码且无失败标记的输出；补齐通用 `E:` 行。未知状态一律失败，走既有双文件回滚。
- 回执：判据只返回刷新失败原因，回滚结果由实际 rollback 返回后追加，避免回滚失败时仍声称「已回滚」。新增失败原因同时提供中英文。
- 复验：`SourceSettingsTest` 覆盖清洁零退出、非零空输出、未知退出、超时、读取/清理失败、截断、零退出失败标记与双语文案；`ProcIoTest` 使用真实宿主子进程验证退出码保留；既有 `ProcIoSettlementFixtureTest` 继续验证读取失败与清理结算。具体结果以本 PR 记录为准。
- 验证边界：用户要求全程不使用 ADB 或模拟器；未做设备验证，未运行 Android apt 或制作发布候选。发布前须补齐设备证据。
