# 屏幕范围门的 ANSI-C / 本地化命令名（#1610）

- 现象：`$'\x73creencap'`、`$'\163creencap'` 的静态词面不含 `screencap`，旧判据允许执行。
- 真因：两端的 `isRuntimeCommandName` 显式排除 `$'…'` / `$"…"`，而 quote removal 没有实现 ANSI-C 转义解码或本地化展开，不能证明实际命令身份。
- 修法：引擎与壳侧删除这项豁免，命令位置统一返回 `deny-unparsed`。普通引号、参数位置和可认证虚拟屏命令保留原有判据。共享 fixture 同时覆盖十六进制、八进制、绝对路径、嵌套与允许对照。
- 复验：见本 PR 验证记录；共享 fixture 由 `node scripts/gen-screen-scope-fixture.mjs` 同步，Node / Kotlin 两端消费相同输入。
- 验证边界：用户明确要求全程不使用 ADB 或模拟器；未做设备验证，不代表最终 APK 或 Android shell 上的设备验收结论。进入发布候选前仍须补齐仓库要求的设备证据。
