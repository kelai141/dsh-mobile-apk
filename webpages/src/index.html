关于 dsh-mobile

dsh-mobile 是 DeepSeek Harness 的安卓客户端封装。 它在应用内运行一个内嵌的 Termux 快照与 Node 引擎，并向模型暴露安卓平台能力（无障碍、虚拟屏、通知、文件访问等）， 因此可以在手机上直接使用 DeepSeek Harness 的完整能力。

该下载哪个架构

绝大多数手机是 arm64（即 arm64-v8a / AArch64）；MuMu 等安卓模拟器通常是 x86_64。 两个安装包体积相近，无法凭体积区分。装错架构不会被系统拒绝安装，而是在启动引擎时失败， 所以请以页面上方自动识别的结果为准；若识别不准可用「换另一个架构」手动切换。
